<objective>
Rewrite blog/index.html and portfolio/index.html as Jekyll Liquid templates so any visitor sees
post and project listings without JavaScript.

Purpose: Both files currently display "Loading..." placeholders that populate from localStorage
via content-loader.js — invisible to any visitor who hasn't previously used the admin panel.
This plan replaces both placeholders with static Jekyll Liquid loops rendered at build time.
It also removes all script tags (per D-04) from both pages, which is a prerequisite for Plan
02-04's git rm of the JS files.

Output:
- `blog/index.html` — full standalone HTML page with empty frontmatter enabling Liquid processing.
  The #blog-posts-list div is replaced by a `{% for post in site.posts %}` loop.
- `portfolio/index.html` — same pattern. The #portfolio-list div is replaced by a
  `{% for item in site.data.portfolio %}` loop.
Both files have the Admin nav link removed and all 5 JS script elements removed.
</objective>

```html
<!--
  Blog home — Jekyll Liquid renders all posts at build time.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0"/>
  <meta name="description" content="Kanha's Study Journal — notes on algorithms, systems, ML, and building things." />
  <title>Blog | Kanha's Study Journal</title>
  <link rel="stylesheet" href="../assets/css/style.css" />
  <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.0.0/css/all.min.css" />
</head>
<body>
  <header>
    <div class="header-content">
      <h1>Kanha Songeam</h1>
      <p class="subtitle">AI/ML Engineer &amp; Developer</p>
      <nav>
        <a href="{{ '/' | prepend: site.baseurl }}">Home</a>
        <a href="{{ '/portfolio/' | prepend: site.baseurl }}">Portfolio</a>
        <a href="{{ '/blog/' | prepend: site.baseurl }}" class="active">Blog</a>
        <a href="{{ '/' | prepend: site.baseurl }}#contact">Contact</a>
      </nav>
    </div>
  </header>

  <main>
    <section class="latest-blog">
      <h2>Blog Posts</h2>
      <div class="card-list">
        {% if site.posts.size == 0 %}
          <div class="empty-state">
            <h3>No posts yet</h3>
            <p>Check back soon!</p>
          </div>
        {% else %}
          {% for post in site.posts %}
            <a class="card" href="{{ post.url | prepend: site.baseurl }}">
              <div class="card-content">
                <span class="date">{{ post.date | date: "%B %-d, %Y" }}</span>
                <h3>{{ post.title }}</h3>
                <p>{{ post.excerpt | strip_html | truncatewords: 30 }}</p>
                <span class="read-more">Read More &rarr;</span>
              </div>
            </a>
          {% endfor %}
        {% endif %}
      </div>
    </section>
  </main>

  <footer>
    <div class="footer-content">
      <p>&copy; 2026 Kanha Songeam. All rights reserved.</p>
    </div>
  </footer>
</body>
</html>
```
