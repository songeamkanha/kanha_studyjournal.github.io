Liquid variables available inside `_layouts/post.html`:
  {{ page.title }}                              — string from post frontmatter `title:`
  {{ page.date }}                               — Time object from post frontmatter `date:`
  {{ page.date | date_to_xmlschema }}           — ISO 8601 string for <time datetime="...">
  {{ page.date | date: "%B %-d, %Y" }}          — human format e.g. "April 26, 2026"
  {{ content }}                                 — rendered Markdown body of the post

Theme inheritance via frontmatter `layout: default`:
  - jekyll-theme-minimal's _layouts/default.html provides:
    - <html>, <head>, <meta charset>, <meta viewport>
    - Theme stylesheet link
    - {% seo %} tag (already includes jekyll-seo-tag output)
  - DO NOT add {% seo %} to post.html — duplicating creates duplicate <meta> tags

Post frontmatter contract (from CLAUDE.md ## Post Frontmatter Schema):
  required: title, date, tags, excerpt
  optional: series, series_order, featured, updated
  Phase 1 test post uses required-only.

Jekyll routing contract:
  filename `_posts/YYYY-MM-DD-slug.md` + `permalink: pretty` in _config.yml
    → URL `/YYYY/MM/DD/slug/` (trailing slash)
  `_posts/2026-04-26-hello-world.md` → `/2026/04/26/hello-world/`

    - Both `index.md` and `index.html` resolve to `_site/index.html` during Jekyll build; whichever Jekyll processes last overwrites the other, producing unpredictable output (INFRA-03).
    - No content is lost: the Markdown body in `index.md` duplicates `index.html` and is entirely inside HTML comments.

    Do NOT use `rm -f` or delete via file editor — git must track the removal.
    Do NOT attempt to preserve any content from `index.md` — nothing is worth preserving (D-07 explicitly states this).

| Theme gem → rendered HTML | jekyll-theme-minimal's default.html injects `{% seo %}` and stylesheet — executor must not duplicate these |
